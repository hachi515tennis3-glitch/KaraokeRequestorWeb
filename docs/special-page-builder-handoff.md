## 今回完了した内容

## 2026-07-14 追加対応

### 歌手と楽曲の関連

- `songs[].artist_relation_mode` を追加した。
  - `explicit`: `artist_ids` をそのまま使用する。空配列も明示値として扱う。
  - `legacy_inference`: 歌手名から完全一致で推定する。
- 旧データ推定は「複合歌手名の完全一致」を最優先し、該当レコードがない場合だけ `&`、`＆`、`+` などで分割して個人歌手へ関連付ける。
- タグ・かな・CVの部分一致を関連付け根拠にしない。
- 関連方式を持たない旧v2で、完全一致歌手IDと部分一致由来の余分なIDが同時保存されている場合に限り、完全一致IDへ修復する。
- 現行データで、月見ヤチヨ、かぐや、複合歌手の曲数がそれぞれ `2曲 / 4曲 / 3曲` となることを実ブラウザで確認した。

### 導入ビジュアル

- 上段サマリーへ独立した画像、ぼかし、色面濃度、表示方法、基準位置を追加した。
- 単純な件数ピルを `SONGS / ARTISTS / TYPES` の小型メトリクス表示へ変更した。
- 件数表示は非表示にもできる。歌手数は曲に実際に関連する一意な歌手IDから算出し、保存値は持たない。
- ロゴ画像、幅、左・中央・右配置を追加した。ロゴ指定時は上段と固定ナビの文字ロゴを画像へ置き換える。

### 配色・フォント・演出

- 個別配色を有効にした場合、ページ、パネル、本文、補助文字、アクセント2色、強調色を変更できる。
- 個別配色を無効にすると既存プリセットを使うため、プリセット切替との互換性を維持する。
- 本文、見出し、ナビのフォントを個別指定できる。
- `assets/font/` の WOFF2 / WOFF / TTF / OTFをローカルフォントとして読み込める。ファイルマジックと容量を検証する。
- 画像ホバー色、濃度、合成方法、拡大率を指定できる。
- `fade / rotate / unclip / zoom` のスクロール登場演出を追加した。JavaScript非対応時は表示を維持し、省モーション設定時は演出を停止する。
- SONGSは常時展開、初期展開の折りたたみ、初期閉じる折りたたみを選べる。

### ショート動画

- 導入部の下へ最大4本を並べる共通動画帯を追加した。
- PCは自動グリッド、スマホは横送りとし、10レイアウトへ個別実装を複製していない。
- `preload="none"` と可視判定を使い、画面に入った動画だけ読み込み・再生し、画面外では停止する。
- 省モーション設定時は自動再生しない。大容量動画アップロードの進捗UIは次段階とする。

## 2026-07-14 MOVIE・導入デザイン再構成

### スキーマと互換性

- スキーマをv3へ更新した。v2の曲、歌手、安定ID、`mini_videos` はそのまま読み込む。
- 旧プロジェクトに新しい設定がない場合は、導入高さ190px、従来パネル、ネイティブ操作付き動画グリッドを使う。編集画面で保存するとv3設定へ移行する。
- 動画データ形式は `content.mini_videos[].{id,title,src,poster}` のまま、上限だけ4本から8本へ拡張した。

### 映像ショーケース

- `grid / editorial_carousel / cinema_strip / floating_frames` の4表示を追加した。
- 中央映像、左右プレビュー、PREV/NEXT、現在位置、円形再生ボタンを共通レンダラーで生成する。
- 矢印キー、Home/End、横スワイプ、左右プレビュー選択に対応した。縦スクロールを妨げない距離判定を入れている。
- 中央動画だけ遅延読込し、切替時は旧動画を停止する。手動再生は音声あり、自動再生を選んだ場合だけミュート再生する。
- 配置は導入直後、PICKUP直前、PICKUP直後から選べる。PICKUP非表示時は導入直後へ退避する。
- 高さ240-720px、横幅いっぱい・左・中央・右寄せ、見出し2種を編集できる。
- MP4/WebMを素材ライブラリから `assets/video/` へ追加できる。上限は100MBだが、PHP/XAMPP側のアップロード上限も別途適用される。

### 導入ビジュアルとロゴ

- 導入レイアウトを `classic_panel / editorial_overlay / type_only / split_stage` から選べる。
- 高さ、内容の左右配置、縁取りなし・罫線・ガラス面を編集できる。
- 画像なしでもグラデーション、罫線、タイポグラフィで成立する背景を追加した。
- ロゴはヘッダーと導入部、ヘッダーのみ、導入部のみ、画像不使用を選べる。
- ロゴ処理は背景なし、柔らかな色面、淡い発光の3種。幅と導入部最大高さも独立して調整する。
- 画像に矩形背景が焼き込まれている場合は自動除去しない。透過PNG/WebP/SVGを推奨し、読込失敗時は文字ロゴへ戻す。

### プリセットとレイアウト

- 配色を10種から18種へ増やした。明色プリセットは本文色・補助文字色・明暗面もプリセット側で持ち、個別配色時は明るさを手動指定できる。

- 参照サイトからは、中央映像を主役にして左右候補を見せる情報階層と前後操作だけを抽出し、色・装飾・作品固有表現は複製していない。
